# 2x2x3 LED panel

Final board: `build/2x2x3-LED-Panel.kicad_pcb`.
Open `build/2x2x3-LED-Panel.kicad_pro` for the complete KiCad project.

Copied from 2x2x4. Four PT4115 channels remain, each driving three series LEDs.
Six warm LEDs use C49435727 (2800–3100 K); six cool LEDs use C49435731
(6000–7000 K). Both are HONGLITRONIC HL-AS-2835D68W-2C-S1-08L-PCT-HR3(R9)-K3.

R1–R4 and R13–R16 are now 1.2 Ω, 1%, 0805 UNI-ROYAL 0805W8F120KT5E,
C17381. Each channel uses two in parallel, retaining the existing circuit and
resistor locations: Rsense = 0.600 Ω; nominal ILED = 0.100 V / 0.600 Ω = 166.7 mA.
Each resistor dissipates approximately 8.3 mW, against its 125 mW rating.
These are parallel current-sense resistors, rather than a voltage divider.
The old instance names `sense_1r` and `sense_4r7` are intentionally retained to
preserve reference designators; their actual values and BOM entries are 1.2 Ω.

The new Schrune `parts install` command installed both LED variants. Its imported
LED footprints differed from each other and from the shared manufacturer
datasheet. Both local source footprints were corrected using KiCad's board API
to the recommended pattern: pin 1 cathode 2.05 × 2.30 mm, pin 2 anode
1.30 × 2.30 mm, with 0.50 mm copper separation. Pin 1 is the large pad.
The cool footprint's incorrect through-hole attribute was also corrected to SMD.
Models supplied by the importer were retained; they are visual representations,
not a dimensional qualification of the package.

All 46 non-LED components retain their exact positions, rotations, sides, pad
dimensions, pad positions and electrical nets. All 110 non-LED tracks/vias are
unchanged. Only LED copper was rebuilt; zones were refilled. The board remains
75 × 30 mm with all four mounting holes unchanged. Original board graphics,
including the old 2x2x4/version silkscreen, are preserved as requested.

Validation on KiCad 10.0.4:

- DRC: zero violations and zero unconnected items.
- Schematic parity: zero issues.
- Exported schematic netlist matches every populated PCB pad/net exactly.
- ERC: zero electrical errors; 58 symbol-library warnings because Schrune emits
  embedded symbols without a named library prefix. These were not suppressed.
- Front copper/silkscreen rendering was visually checked against the LED drawing.
- `verification/final-audit.json` records the preservation checks.

The manufacturer specifies 180 mA absolute maximum LED forward current and
temperature derating. 166.7 mA is the nominal setting, not a guaranteed current
range. Allowing ±5% driver accuracy and ±1% sense resistance gives approximately
156.8–176.8 mA before switching ripple, temperature drift and other effects.
Check peak LED current, cold regulation headroom and LED solder/junction
temperature on a prototype. At 6 V nominal, all 12 LEDs at full drive consume
approximately 12 W before driver losses; cooling needs verification. The
datasheet's 5.6–6.6 V range is specified at 150 mA, not at 166.7 mA.

| Total, rounded | **$63.99** | **$68.31** |
| Per board | **$2.13** | **$2.28** |

Increase: $4.314 for the run, approximately $0.144 per board (6.74%).
The extra extended-part fee is the stocked 1.2 Ω sense-resistor line.
All BOM lines had sufficient reported stock for 30 boards; each LED variant
requires 180 pieces, versus reported stock of 1,153 warm and 12,953 cool.
Headers are excluded from assembly by the source's existing `place = false`.

Raw `schrune tools jlc-bom -n 30` reports are retained in
`verification/jlc-bom-old-30.txt` and `verification/jlc-bom-new-30.txt`.
They report $60.15 and $64.85 respectively. The tool's filename-based footprint
lookup counts only 48 joints per board, missing some autogenerated assets.
`verification/cost-comparison.cjs` uses Schrune's JLC BOM/pricing functions and
economic calculator with the actual PCB pad counts: 128 old, 120 new.
The table above includes that correction; no BOM CSV was manually edited.
These are estimates, not JLC quotes. PCB fabrication, shipping, tax, attrition,
minimum purchase quantities and any additional assembly/panel fees are excluded.

## Rebuilding

From this folder, run `node C:/Code/Schrune/src/app.js build`. Supplying an
explicit `main.schrune` argument instead bypasses the manifest's project name
in this installed Schrune version and creates a project named `main`.

The installed LED parts are in `parts/`; the generic inductor remains in
`parts/autogenerated/` and the parts lock. It is omitted from the explicit
installer manifest to avoid installing a duplicate, ambiguous asset directory.

`verification/layout.py` reconstructs the constrained layout from the original
board using `verification/generated.kicad_pcb` as the clean Schrune footprint
and net reference. It requires KiCad's Python environment. The board was edited
through KiCad's pcbnew API: this installed KiCad has no headless IPC server and
there was no running IPC endpoint. No PCB text editing was used for placement,
footprint correction or routing.

Manufacturer drawing reviewed: `../research/led-options/C49435727.pdf`, page 2
(specification B-22-A-1355, December 20, 2022). The shared datasheet is also at
https://datasheet.lcsc.com/datasheet/pdf/36b5a6a5d7d2a5c9744494875f27b2d1.pdf?productCode=C49435731 .
